### 🏛️ About the Project
**BhoomiVerify** is an end-to-end Geospatial Land Parcel Visualization, Cadastral Boundary Analysis, and Title Consistency Verification System built to improve transparency in land record management.

- **Frontend**: Next.js 14, Tailwind CSS, Leaflet GIS, Lucide Icons, Multi-Language i18n
- **Backend**: FastAPI (Python), SQLAlchemy, SQLite / PostgreSQL, Spatial Analytics Engine
